Masonry 技术实现方式

视觉风格确认：支持 dark/light 主题切换

Masonry 布局用什么技术实现？

这直接影响页面的技术展示效果和兼容性

A

纯 CSS (columns / grid)

使用 CSS columns 或 grid-template-rows: masonry。无 JS 依赖，性能最好。但 masonry 属性目前只有 Firefox 支持，columns 排列顺序是从上到下再从左到右（不是自然的从左到右阅读顺序）。

B

原生 JS 实现 (推荐)

用 JS 计算每个元素位置，绝对定位排列。完全控制布局逻辑，支持动画过渡、动态添加/删除、列数变化平滑过渡。展示纯 JS 能力，无外部依赖。

C

使用库 (Masonry.js / Isotope)

成熟的 masonry 库，功能完善。但作为展示实力的页面，用库显得技术含量不高，而且增加外部依赖。
