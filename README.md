# huangssssx.github.io

> Front-end development portfolio — showcasing landing pages, e-commerce experiences, and interactive layouts built with vanilla HTML, CSS, and JavaScript.

**Live Site:** [huangssssx.github.io](https://huangssssx.github.io)

---

## Projects

### [Main Portfolio](./main-websit/)

The hub page — a clean, Apple-inspired portfolio that links to all sub-projects. Responsive design with smooth scroll, card-based layout, and Inter typeface.

### [Landing Page](./landingpage/) — WebCraft Pro

A production-grade landing page with **Lighthouse 100/100/100/100**. Zero frameworks, zero build step. Features 10 advanced visual effects (liquid glass navbar, scroll-driven SVG, 3D mockup, canvas particles, etc.), critical CSS inlining, service worker offline caching, and Brotli compression — total payload under 20 KB.

### [E-Commerce Website](./e-commerce-websit/) — Northstar

A premium home & living e-commerce site with dark/light theme toggle, frosted glass UI, product pages, contact form, and multi-page navigation. Custom font loading, CSS custom properties design system, and responsive grid layout.

### [Masonry Layout](./masonry-layout/)

A responsive masonry grid showcase built with Isotope.js. Features monopo saigon-inspired dark aesthetic, ambient gradient background, scroll-triggered lazy loading (96 items, 16 per page), adjustable columns (2–5), three content modes (Gallery / Cards / Mixed), and scroll-reveal animations.

---

## Tech Stack

- **HTML5** — Semantic markup, JSON-LD structured data, Open Graph
- **CSS3** — Custom properties, `backdrop-filter`, `@keyframes`, responsive grid
- **Vanilla JavaScript** — Zero dependencies across projects
- **Service Worker** — Offline caching support
- **Isotope.js** — Masonry layout engine (masonry-layout only)

**No React. No Vue. No Tailwind. No Webpack. No build step.**
