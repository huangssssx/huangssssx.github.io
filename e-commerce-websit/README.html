Northstar E-Commerce Website

A premium furniture e-commerce website built with vanilla HTML, CSS, and JavaScript. Features a light/dark theme toggle, responsive design, scroll-reveal animations, a product detail page with image gallery, a multi-step contact form with validation, and a clean editorial design inspired by Scandinavian minimalism.

Live Demo GitHub Repository

Features

  • Light / Dark theme toggle with localStorage persistence and prefers-color-scheme detection
  • Responsive layout — mobile-first design with fluid typography and flexible grids
  • Scroll-reveal animations via IntersectionObserver with prefers-reduced-motion support
  • Product detail page with image gallery, thumbnail switching, material showcases, and lifestyle images
  • Contact form with client-side validation, honeypot spam protection, and accessible error messages
  • Hero carousel with auto-advance, dot navigation, and touch/swipe support
  • Sticky header with scroll-aware background transition
  • Typography using Cormorant (serif headings) and Montserrat (body text) via self-hosted fonts
  • No build step — pure HTML, CSS, and vanilla JavaScript

Accessibility

  • Semantic HTML with <header>, <main>, <footer>, <article>, <nav>
  • aria-label on interactive elements
  • aria-live="polite" on form status messages
  • prefers-reduced-motion disables scroll-reveal animations
  • Keyboard-accessible navigation and form controls
  • Color contrast meets WCAG AA guidelines
